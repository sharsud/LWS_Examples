# Design System & UI/UX Guidelines

## 🎨 Color Palette (Tailwind Brand Specs)
- **Primary Brand Color:** Indigo / Slate Deep (`bg-indigo-600`, `hover:bg-indigo-700`)
- **Background Neutral:** Slate light (`bg-slate-50`)
- **Card Background:** Pure white (`bg-white`) with soft borders (`border border-slate-200`)
- **Text Primary:** Slate dark (`text-slate-900`)
- **Text Muted:** Slate muted (`text-slate-500`)

## 📐 Typography & Layout
- **Font Family:** Inter or Sans-Serif system stacks.
- **Card Layout:** Max-width container (`max-w-4xl mx-auto`), rounded corners (`rounded-lg`), subtle shadow (`shadow-md`).

## 👆 Component Patterns
- **Buttons:** Rounded padding (`px-4 py-2 rounded-md font-medium text-sm transition-colors`).
- **Form Fields:** Full width, clear border outlines (`w-full border border-slate-300 rounded-md focus:ring-2 focus:ring-indigo-500`).
- **Modals:** Fixed overlay with translucent backdrop (`fixed inset-0 bg-slate-900/50 flex items-center justify-center z-50`).
